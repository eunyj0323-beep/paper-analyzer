# 논문 분석 리포트

논문 PDF를 올리면 AI가 다음 네 가지를 한국어 리포트로 정리해 주는 웹 앱입니다. 한국어·영어 논문 모두 됩니다. API 키가 없어도 무료 모드(Google Gemini)로 분석할 수 있고, 본인 Claude API 키를 넣으면 Claude로 분석합니다.

| 탭 | 내용 |
|---|---|
| 요약/핵심 주장 | 기본 정보(제목·저자·연도·게재지), 연구 목적·연구질문·주요 발견·결론 5~8문장 요약, 핵심 주장 |
| 연구방법·통계기법 | 연구설계, 표본(대상·표본 수·표집 방법), 측정도구, 분석 단계별 통계기법 표 |
| 인용·참고문헌 | 핵심 선행연구 5~10개(저자·연도·핵심 내용·인용 맥락), 참고문헌 목록 원문 |
| 차별점·갭 분석 | 이론적·방법론적 차별점, 저자가 밝힌 한계, 후속 연구 제언, 추가 연구 갭 |

결과는 마크다운(.md)이나 워드(.docx)로 내려받을 수 있습니다.

- **여러 편 비교**: 2~3편을 함께 올리면 각 논문 분석과 함께 논문끼리 비교한 리포트(한눈에 비교 표, 공통점, 차이점, 함께 읽었을 때 보이는 연구 갭)를 만듭니다.
- **내 보관함**: 분석한 리포트는 자동으로 저장되고, AI가 분야·연구유형·키워드를 붙여 분류합니다. 검색어로 리포트 내용 전체나 특정 항목(예: 연구방법만)을 찾고, 분야·연구유형·내 태그로 걸러 볼 수 있습니다. 보관함에서 논문 2~3개를 골라 비교 리포트를 만들 수도 있습니다.
- **스캔본 PDF**: 글자를 뽑을 수 없는 PDF(스캔본, 글꼴이 깨진 파일)는 AI가 PDF 파일을 직접 읽고 분석합니다(100쪽·20MB 이하).

---

## 쓰는 방법 (배포된 웹 앱)

1. 앱 주소를 엽니다.
2. 논문 PDF를 올리고 **분석 시작**을 누릅니다. 2~3편을 올리면 **분석하고 비교 리포트 만들기** 버튼이 나옵니다. 키가 없으면 무료 모드로 분석합니다. 보통 몇 분 걸립니다.
3. 탭에서 결과를 보고, 필요하면 다운로드합니다. 다른 논문을 분석하려면 오른쪽 위 **새 분석 시작**을 누릅니다.
4. 위쪽 **내 보관함**에서 지금까지 분석한 리포트를 검색·분류해 볼 수 있습니다.

보관함은 **지금 쓰는 브라우저에만** 저장됩니다(브라우저 localStorage). 다른 사람은 볼 수 없고, 다른 기기나 브라우저에서는 보이지 않으며, 브라우저의 사이트 데이터를 지우면 사라집니다. 보관함 아래 **백업 · 복원**에서 전체를 파일 하나로 내려받고 다시 불러올 수 있습니다.

본인 Claude API 키가 있으면 왼쪽 사이드바에 붙여넣고 모델을 고른 뒤 분석하세요. 입력한 키와 올린 PDF는 앱에 저장되지 않습니다.

### 무료 모드 (Google Gemini)

- 키 없이 분석할 때 쓰입니다. 앱 관리자가 서버에 넣어 둔 Google Gemini 무료 키로 `gemini-3.5-flash-lite` 모델을 쓰고, 이 모델이 붐비거나 한도가 차면 `gemini-3.8-flash`로 자동 전환합니다.
- 모든 사용자가 하루 사용량을 나눠 씁니다. 한도가 차면 다음 날(한국 시간 오후 4~5시 초기화) 다시 쓸 수 있습니다.
- 논문 내용이 Google로 전송되며, 무료 등급 약관에 따라 **Google 서비스 개선에 쓰일 수 있습니다**. 공개 전 원고는 본인 Claude 키로 분석하세요.
- 무료 사용량을 아끼려고 네 항목을 한 번의 요청으로 받습니다. 응답이 잘못 오면 다시 분석해 보세요.

### Claude API 키 발급

1. https://platform.claude.com 에 로그인합니다.
2. 결제 수단을 등록하고 크레딧을 충전합니다. API는 claude.ai 구독과 별도로 사용한 만큼 청구됩니다.
3. API Keys 메뉴에서 새 키를 만들고 복사합니다. 키는 만들 때 한 번만 보이니 안전한 곳에 보관하세요.

### 비용

무료 모드는 비용이 들지 않습니다. Claude로 분석하면 비용이 **입력한 키의 계정**에 청구되고, 분석이 끝나면 화면에 실제로 쓴 토큰 수와 대략적인 비용이 표시됩니다.

| 모델 | 입력 (100만 토큰당) | 출력 (100만 토큰당) | 특징 |
|---|---|---|---|
| Claude Opus 5.5 (기본값) | $4.00 | $20.00 | 가장 정확함 |
| Claude Sonnet 5.5 | $2.00 | $10.00 | 중간 |
| Claude Haiku 5.5 | $0.10 | $0.50 | 가장 저렴함, 대신 분석이 덜 꼼꼼할 수 있음 |

가격은 2026년 11월 기준입니다. 최신 가격은 Anthropic 공식 가격 페이지에서 확인하세요.

## 배포 방법 (Streamlit Community Cloud, 무료)

1. 이 폴더를 GitHub 저장소에 올립니다. `.env` 파일은 `.gitignore`에 들어 있어서 올라가지 않습니다.
2. https://share.streamlit.io 에 GitHub 계정으로 로그인합니다.
3. **Create app** → GitHub 저장소에서 배포를 고르고, 다음처럼 입력합니다.
   - Repository: 올린 저장소
   - Branch: `main`
   - Main file path: `main.py`
   - Advanced settings → Python version: 3.12
4. **Deploy**를 누르면 몇 분 뒤 `https://<이름>.streamlit.app` 주소가 생깁니다. 이 주소를 공유하면 됩니다.

### 무료 모드 켜기

1. https://aistudio.google.com/apikey 에서 Google 계정으로 로그인하고 API 키를 만듭니다. 결제 정보 없이 무료 등급으로 쓸 수 있습니다.
2. Streamlit 앱 관리 화면 → **Settings → Secrets**에 아래 한 줄을 넣고 저장합니다. 1분쯤 뒤 반영됩니다.

```toml
GEMINI_API_KEY = "여기에_발급받은_키"
```

Secrets에 `ANTHROPIC_API_KEY`를 넣으면 키를 입력하지 않은 사람도 내 Claude 키로 분석하게 됩니다. 이 경우 모든 사용자의 비용이 내 계정에 청구되니 주의하세요.

## 내 컴퓨터에서 실행

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run main.py
```

브라우저에서 http://localhost:8501 이 열립니다. 무료 모드를 쓰거나 매번 키를 입력하지 않으려면 `.env.example`을 `.env`로 복사하고 키를 넣어 두세요.

## 동작 방식

- **텍스트 추출**: pdfplumber와 PyMuPDF로 PDF의 글자를 뽑아 더 잘 읽힌 쪽을 씁니다. 둘 다 실패하면 PDF 파일을 AI에 그대로 보냅니다.
- **비교 리포트**: 원문 대신 각 논문의 분석 리포트를 바탕으로 비교해서, 요청이 짧고 무료 사용량도 적게 씁니다.
- **긴 논문 처리**: 논문 전체가 10만 토큰 이하면 통째로 분석합니다. 학위논문처럼 그보다 길면 본문을 여러 조각으로 나눠 각각 핵심 내용(수치, 인용, 한계 등)을 압축한 노트를 만든 뒤, 그 노트와 참고문헌 원문으로 분석합니다.
- **항목별 분석 (Claude)**: 네 탭을 각각 따로 요청합니다. 참고문헌 파싱 등 한 항목이 실패해도 나머지 결과는 정상적으로 나옵니다. 논문 텍스트는 프롬프트 캐싱을 써서 두 번째 요청부터 입력 비용이 크게 줄어듭니다.
- **거절 대비**: Opus·Sonnet 모델은 안전 필터가 요청을 잘못 거절할 경우 다른 모델로 자동 재시도하는 서버 측 fallback 기능을 켜 두었습니다.

## 알아둘 점

- 스캔한 이미지 PDF는 AI가 PDF를 직접 읽는 방식으로 분석합니다. 텍스트 추출보다 느리고, 100쪽·20MB를 넘으면 필요한 쪽만 잘라서 올려야 합니다.
- 2단 편집 논문이나 표는 추출 과정에서 순서가 섞일 수 있습니다.
- AI 분석 결과는 틀릴 수 있습니다. 특히 표본 수, 통계 수치, 참고문헌은 인용하기 전에 원문과 대조하세요.

```
analyzer.py       Claude·Gemini API 호출, 프롬프트, 긴 논문 처리

```
